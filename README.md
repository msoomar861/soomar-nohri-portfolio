# Soomar.dev Portfolio

A responsive personal and academic portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Run locally
Open `index.html` in a modern browser. For a local development server, run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Deploy
Upload the folder to a GitHub repository and enable GitHub Pages from repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Before publishing
- Confirm the profile photo and campus image are the ones you want public.
- Review all wording and dates.
- Add GitHub and any other public profile URLs when ready.
- Replace the StudentOS artwork placeholder with real app screenshots if desired.
- The CV is not published as a raw download because the uploaded CV contains personal identifiers and residential/contact details. The contact section offers an email route instead.
